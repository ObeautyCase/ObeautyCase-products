# Documentation Index

This directory contains original reference materials for brands, distributors, wholesalers and procurement teams evaluating professional makeup cases and beauty storage products.

Each document addresses one practical buyer question. It is not a duplicate of an Obeautycase product page or blog article.

## OEM & Product Specification

- [Makeup Case RFQ Specification Checklist](oem/makeup-case-rfq-specification-checklist.md) — a pre-enquiry checklist for defining the product configuration, sample requirements and quotation scope.

## Planned Documentation Areas

- **Materials:** how to read a complete construction specification, including substrate, surface finish, frame and hardware.
- **Selection:** how working environment, storage load and transport needs affect a case brief.
- **OEM/ODM:** specification, sampling and approval documents for procurement teams.
- **Quality:** practical inspection vocabulary and documentation boundaries.

## Editorial Standard

Information here is intended for planning and supplier communication. Product availability, materials, MOQ, lead time, compliance documentation and final specifications must be confirmed for the relevant model, quantity and destination market before an order is placed.

For the current product range and direct enquiries, visit [Obeautycase](https://obeautycase.com/).
